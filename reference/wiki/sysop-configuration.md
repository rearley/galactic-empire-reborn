# Sysop configuration

An installation of Galactic Empire can be highly customized by the system operator.

The main configuration file is MBMGEMSG.MSG. Nearly all of the game's customizable options, as well as much of the menus and "look and feel" of the game, can be adjusted here.

The ship configuration file is MBMGESHP.MSG. You can define new CPU or player ships, or change their attributes.

MBMGEHLP.MSG can also be edited if the sysop wishes to change anything displayed in the in-game help.

The text of the "Whats New!" option on the main menu is located in MBMGEMNU.TXT, and can be edited. Whether or not to show this option and what to call it on the main menu is in MBMGEMSG.MSG.
