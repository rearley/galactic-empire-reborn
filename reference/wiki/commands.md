# Commands

Source: https://manicpop.org/gewiki/index.php?title=Commands

All commands can be entered as their first 3 characters (e.g. `aba` for abandon).
Commands are case-insensitive.

## Command Argument Conventions

- `[SHIP LETTER]` — single letter identifying a ship shown in your scan
- `@` — shorthand for your currently locked target
- `[item]` — first 3 letters of item name (men, mis, tor, ion, flu, foo, fig, dec, tro, zip, jam, min, gol, spy)
- `[quantity]` — numeric amount
- `[percent]` — 1–100
- `[degrees]` — 0–359
- `[speed]` — 1–99 for impulse, 1–999 for warp
