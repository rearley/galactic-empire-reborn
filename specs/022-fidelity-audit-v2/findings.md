Severity: `HIGH` = exploitable / game-breaking, `MEDIUM` = wrong but bounded, `LOW` = cosmetic.
Disposition: `fixed` | `deferred` | `n/a` (intentional TS-only behavior, documented).

ID prefix: `S-` scanners, `A-` AI targeting, `P-` persistence, `C-` combat ranges.

### Cross-cutting notes (T5 scanners walk)

- **Per-class scanRange seed pin result (resolves T4 cross-cutting question):** 17 of 18 classes match wiki authoritative values. **One drift**: Vakory Survey Drone (class 33) seed=20000 vs wiki=25000 (S-006, fixed). **One suspect-but-not-drift**: Cybertron Battle Cruiser (class 22) wiki literally says "1000" → 0.1-sector scan range → effectively no scan. Seed matches wiki. Original `.cnf` value is unrecoverable from current C source; deferred to design discussion. Could be wiki typo (likely "15000" or "1500") but no authority to override.
- **"Basic scanners reveal the whole map" — verdict: HALF-CONFIRMED.** Interceptor on TS shows ~10-sector radius via `sca lo` — NOT the whole map. But (a) the C-canonical `sca lo` for *any* ship reveals 10× scanRange = whole galaxy for ships ≥ Battle Cruiser (S-001), and (b) the current TS `sca lo` for Dreadnought (50-sector projected radius) and Death Star (100 sectors) already covers the whole galaxy. After the S-001 fix, **all** classes see the wide overview via `sca lo` (C-canonical), and only `sca ra` is the in-range tactical. So the player's "basic scanners reveal the whole map" is **C-canonical for `sca lo`** and is not a bug — but the bug exists in TS today inverted: `sca lo` is too narrow for small ships, too wide for big ships. S-001 fix harmonises this.
- **Audit 020 F-003/F-004/F-005/F-006 verification:** F-003 ✓ intact (S-011). F-004 ✓ intact (printmap ordering, side-panel matches). **F-005 ✗ regressed** by `d75d337` (S-005, fixed). F-006 ✓ intact (S-012).
- **C-001 phaser-range gate (combat audit 020) is anchored on `ShipClass.scanRange` — confirmed not toothless.** Maximum club is Death Star (1M) = 100 sectors > galaxy width 30 → phaser is effectively galaxy-wide for class 34, but class 34 is admin-only. Among non-admin classes, max scanRange is Dreadnought 500k = 50 sectors. Still covers the galaxy for that class; in practice combat scenarios use Interceptor/Cybertron Scout where 10-sector cap is meaningful. Document as intentional asymmetry for endgame ships.
- **`sca ra` zoom formula unit bug (S-003) was masked by self-consistent test harness.** Tests in `test/unit/scan-ra.spec.ts` use sub-millisector target coords and an algebraic helper that mirrors the broken formula. They pass for the wrong reason. Existing tests are also broken on master for unrelated reason (`scanRender undefined`, 24/25 failing) — investigate separately.
- **`scan ra` does NOT show planets or wormholes** (matches C `scan_ra` which only projects ships + mines). Planets only appear on `scan se` and `scan lo`. Verified.

### Scratch — C-source scan inventory used for the walk

- `cmd_scan` (GECMDS.C:2138) — dispatcher; gates on `tactical != 0` and `jammer > 0`; routes to scan_{sh,pl,ra,se,lo}.
- `scan_sh` (GECMDS.C:2188-2293) — ship detail. `findshp(arg, 1)` (cloak<10). Range gate `ddistance < scanrange`. Reveals: name, class typename, username, teamname, bearing, heading, sector, speed (showarp), tonnage→length/width. If both not at warp: damage, shieldstat, kills. Reverse-detection hint (SCAN1/2/3).
- `scan_pl` (GECMDS.C:2295-2482) — planet detail by `plnum` in current sector. Reveals: name, owner, bearing/distance, environment, resources, items inventory if spy-owned. Wormhole branch reveals name + bearing/distance only.
- `scan_ra` (GECMDS.C:2484-2577) — zoom range scan, level 1..9. `range = scanrange/((10-x)^2)` raw, then `/10000.0` for sector-units. Projects MINES (`.`) and SHIPS (scantab letter). Self at centre `*`. `if SCANFULL → printmapfull else printmap`. No planets, no wormholes.
- `scan_se` (GECMDS.C:2580-2637) — current sector scan, fixed scale. Projects MINES, SHIPS, PLANETS (via `map_planets()`). Sector-relative.
- `scan_lo` (GECMDS.C:2640-2726) — long-range. `range = scanrange * 10.0`. Iterates ALL ships in game, projects via grid. Self at `*`. **No cloak gate** (cloak visible at long range, intentional). NO mines, NO planets.
